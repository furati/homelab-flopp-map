Datenschutzerklärung

Dies ist eine private interne Instanz ohne öffentliches Angebot. Sie ist nur im privaten Netz erreichbar und richtet sich nicht an Dritte.

Die Anwendung basiert auf Flopps Karte von Florian Pigorsch (MIT-Lizenz), Quelle: github.com/flopp/map. Der Betreiber der Originalseite flopp.net ist nicht der Betreiber dieser Instanz.

Es werden keine Daten an Dritte übermittelt, mit Ausnahme der Kartenkacheln: Beim Anzeigen der Karte lädt der Browser Kacheln direkt von OpenStreetMap (tile.openstreetmap.org), von OpenTopoMap (tile.opentopomap.org) und, wenn die Schutzgebiets-Ebene aktiviert ist, vom Bundesamt für Naturschutz (geodienste.bfn.de). Diese Anbieter erhalten dabei die IP-Adresse des Browsers und den sichtbaren Kartenausschnitt (Kachelkoordinaten und Zoomstufe). Marker, Namen und Links werden nicht übertragen. Es gibt keine Webanalyse und keine Ortssuche über Dritte.

Privacy Policy

This is a private internal instance with no public offering. It is reachable only from the private network and is not aimed at third parties.

The application is based on Flopp's Map by Florian Pigorsch (MIT license), source: github.com/flopp/map. The operator of the original site flopp.net is not the operator of this instance.

No data is sent to third parties except for map tiles: when the map is displayed, the browser loads tiles directly from OpenStreetMap (tile.openstreetmap.org), from OpenTopoMap (tile.opentopomap.org) and, if the protected-areas layer is enabled, from the German Federal Agency for Nature Conservation (geodienste.bfn.de). These providers receive the browser's IP address and the visible map section (tile coordinates and zoom level). Markers, names and links are not transmitted. There is no web analytics and no place search via third parties.
